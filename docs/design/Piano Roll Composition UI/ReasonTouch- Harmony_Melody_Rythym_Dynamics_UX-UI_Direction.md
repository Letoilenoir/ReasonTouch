# ReasonTouch — Harmony, Melody, Rythym and Dynamics UX/UI Direction

## Working design brief

> “How can we get all elements to communicate and synchronise to create a realistic coherant composition.”

This document records the UX/UI direction developed from that question.

It is a design/architecture brief rather than an implementation specification.

## 1.Can I create a bassline and have ReasonTouch generate a chord progression to compliment it?

For example the relationship between a chord progression and  a walking bass accompianment relies on the bass being able to "read" the chord progression - can the reverse process be engineered

## 2. How can I get the drums to synchronise with the chord seqeuence/Bassline to accent changes etc?

Are there any academic articles/mathmatical equations that explore these relationships?



## 3. More Complex drum patterns

Accents, fills etc beyond the rudiments, change patterns if direction of composition alters




## 4. Suggest a melody from component parts

Given the established relationship between a chord progression, a bassline and a drum pattern, can we "suggest" or derive a melody from the aggregate of these?
