# Audio Engine Architecture

## Overview
The ReasonTouch audio engine is responsible for real-time audio rendering, mixing, and coordinating musical layers generated by composition engines. It consumes MIDI events, schedules playback, and produces audio frames for output.

## Responsibilities
- Real-time audio rendering  
- Mixing drum, bass, chord, and melodic layers  
- Applying timing, swing, and quantization  
- Managing audio buffers  
- Coordinating with playback transport  
- Responding to MIDI events routed from composition engines  

## Core Components

### AudioEngine
Handles the main render loop, buffer generation, and mixing.

### DrumMachine
Generates drum patterns, applies swing, and outputs MIDI events.

### BassGenerator
Produces basslines based on chord progressions and rhythmic rules.

### ChordSuggestionEngine
Generates chord progressions and harmonic structures.

### MidiRouter
Routes MIDI events to the correct track or instrument.

### PlaybackController
Controls play, pause, seek, tempo, and metronome timing.

## Data Flow
1. Composition engines generate musical structure (drums, bass, chords).  
2. Engines output MIDI events.  
3. MidiRouter distributes events to the correct destination.  
4. PlaybackController manages transport state.  
5. AudioEngine renders audio frames based on incoming MIDI and transport timing.
